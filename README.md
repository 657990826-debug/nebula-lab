# NEBULA LAB — 科研媒体分析工作台

暗色科技风、中文界面的响应式 React 网站，包含：
- 工作台概览与研究活动
- 图片/视频素材画廊：搜索、分类筛选、预览、本地导入、拖放导入
- 剧情/研究记录浏览：章节切换、时间区间、标签和证据说明
- 动画逐帧查看界面：帧序切换、时间戳、关键帧缩略图、观察备注
- 手机与桌面响应式布局

## 运行要求
- Node.js 18 或更新版本
- npm

## 启动
```bash
npm install
npm run dev
```
按终端提示打开本地地址（通常为 http://localhost:5173）。

## 构建生产版本
```bash
npm run build
npm run preview
```

## 当前版本边界
- 画廊中的导入文件使用浏览器本地对象 URL 预览，不会上传到服务器；刷新后导入列表不会持久保存。
- 内置图片和叙事条目为演示内容，图片通过 Unsplash 外链加载。
- 逐帧页面目前是交互式 UI 原型，使用演示图像模拟帧序列；尚未实现真实视频解码、自动提帧、图像差分、OCR、账号系统或云端数据库。
- 如果要将它用于正式科研工作，建议下一阶段接入后端文件存储、项目/权限管理、真实视频提帧服务，以及可导出 JSON/CSV 的分析记录。
